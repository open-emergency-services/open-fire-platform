# How this is run & how you can help

*The short, honest version.*

**This is a public service, built in the open.** The goal is simple: free software for fire departments, so no one has to pay a private-equity firm to do a public job.

## Who's behind it

- Built and maintained by **one person** right now. No venture capital, no investors, no big organization behind it.
- The software is — and will stay — **free and open source** ([AGPLv3](../LICENSE)). You can always self-host it, your data is always yours to export, and the license is chosen specifically so no company can take this code, close it up, and sell it back to departments.

## Where it might go someday (no promises)

This is early, and it may well stay small. But if it grows, here's what *could* help keep it alive — **none of this exists yet:**

- Optional **paid hosting**, for departments that would rather not run their own servers. Self-hosting stays free, forever.
- **Sponsorship or grants** to fund the work — the kind of federal and state grants that already support fire departments.
- Maybe, eventually, a larger organization — run by me or by others — if that's what it takes to make it last.

Whatever happens, the ground rules don't change: **the code stays open, your data stays yours, and we would only ever charge to *run* it for you — never to unlock features.** And if the project is ever abandoned, the code and your data remain yours — you're never stranded.

## How you can help right now

- **Fire departments:** try it, tell us what's broken, help shape it.
- **Developers:** the code is open — jump in.
- **Everyone:** share the story. Most people have no idea this is happening.
- **Push your state:** some states already give their departments software for free. More should. That's the real fix.

*Hosting details, sponsorship links, and any pricing will appear here only if and when they become real. For now, the best support is using it and spreading the word.*
